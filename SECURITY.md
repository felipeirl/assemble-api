# Security Policy

## Supported versions

Only the latest release on `main` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting: **Security → Report a vulnerability** on this repository. Include a description, the affected route or module, and steps to reproduce.

You can expect an acknowledgement within 7 days. Fixes are released as a new version, and the advisory is published after the fix ships.

## Scope

In scope: authentication and authorization, data exposure, injection, and bypasses of the guardrail or rate limits.

Out of scope: denial of service through volume, findings in third-party services, and issues that require a compromised client device.
